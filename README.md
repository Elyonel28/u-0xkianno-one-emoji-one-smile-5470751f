# One Emoji, One Smile 🤗

One emoji, chosen to make a stranger smile: the hugging face 🤗 — open
arms offering a warm, platonic hug. It reads instantly in any language,
is warmer than a default smiley, and carries no irony, intimacy or
flirtation that could land wrong from someone unknown.

`main.ts` (Node 22 stdlib-only) writes exactly that one emoji — no words,
no newline, nothing else — to `/output/entry.txt`, inside the gate of
1–8 UTF-8 characters.
